### Что уже сделано

**[Сайт караоке-клуба «Пятница»](https://pyatnica-kyzyl.ru)** — работающий бизнес в Кызыле.
Онлайн-бронь столов, отдельный экран броней для персонала, меню и цены владелец правит сам
через Google-таблицу. Данные гостей хранятся в РФ по 152-ФЗ.
React 19, Vite, Tailwind 4, Google Apps Script, Yandex Cloud Functions.

**AI-менеджер по продажам в Telegram** — бот квалифицирует входящие заявки, считает смету
по прайсу и отдаёт человеку готового лида. Смету считает функция, а не модель. Промпт
меняется только через evals: 74 юнит-теста и 10 eval-кейсов гоняются в CI на каждый push.
Python 3.12, aiogram 3, Pydantic v2, SQLAlchemy 2, FastAPI, pytest, Docker, GitHub Actions.

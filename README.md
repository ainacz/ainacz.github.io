# Портфолио — Долаан Нурзат

Статический сайт из двух страниц. Сборка не нужна, файлы открываются как есть.

```
index.html          — страница для бизнеса: услуги, цены, работы, порядок работы
dev/index.html      — страница для работодателя: проекты, решения, стек, резюме
styles.css          — общие стили обеих страниц
assets/og.png       — картинка превью 1200×630 для ссылок в мессенджерах
PROFILE-README.md   — текст для README профиля GitHub (в этот репозиторий не нужен)
```

Две страницы, потому что аудитории приходят из разных каналов: в холодную рассылку
и на визитку идёт корень, в отклик на стажировку — `/dev`. Каждая страница говорит
одним голосом вместо одного компромисса на двоих.

## Что осталось заполнить

В коде эти места помечены комментарием `TODO Долаан` и видны на странице как
жёлтые блоки с пунктирной рамкой. Рядом с каждым лежит готовая разметка в
комментарии: раскомментировать, подставить своё, блок-заглушку удалить.

1. `index.html` — отзыв владельца «Пятницы» и одна цифра: разметка лежит
   в комментарии рядом с блоком проекта, раскомментировать и заполнить;
2. `index.html` — запись диалога с ботом: файлы `assets/bot-demo.mp4`
   и `assets/bot-demo.jpg`, сценарий съёмки в отдельном файле `video-demo.md`;
3. `dev/index.html` — ссылка на репозиторий бота и бейдж GitHub Actions;
4. `dev/index.html` — резюме в `assets/rezume.pdf` и кнопка скачивания.

Цены и сроки в услугах уже проставлены.

## Внешние зависимости

Две, обе по ссылке: шрифты Google Fonts (Unbounded, Inter, JetBrains Mono,
Press Start 2P) и библиотека анимаций Motion с CDN. Если что-то не загрузится,
страница отображается полностью: контент по умолчанию видимый, скрипт только
добавляет анимацию поверх.

## Публикация на GitHub Pages

Файлы лежат в корне ветки `main` репозитория `ainacz.github.io`.
Settings → Pages → Source: Deploy from a branch → Branch: main / (root).
Корень открывается по адресу `https://ainacz.github.io`, вторая страница —
`https://ainacz.github.io/dev/`.

## Доступность и качество

- контраст текста проверен (основной текст от 4.5:1, акценты выше 8:1);
- размер интерактивных элементов не меньше 44px;
- `prefers-reduced-motion` уважается: при системной настройке анимации отключаются;
- адаптив проверен на 390, 860 и 1440px;
- `check.py` в этом наборе проверяет целостность разметки, ссылки и якоря.

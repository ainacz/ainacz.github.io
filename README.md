# Портфолио — Долаан Нурзат

Статический сайт для клиентов. Сборка не нужна: главная страница — `index.html`, общие стили — `styles.css`.

Широкий шрифт Unbounded оставлен для крупных заголовков. Кнопки, меню и мелкие подписи набраны Inter. Точечный фон сохранён.

Проверка файлов и внутренних ссылок: `python check.py` из корня проекта.

Для локального просмотра: `python -m http.server 8766`, затем открыть `http://localhost:8766/`.

Публикация на GitHub Pages: ветка `main`, папка `/ (root)`. Локальные изменения сами по себе не публикуются.
